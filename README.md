# ReviewGuard — Fake Review Detection

Flask full-stack application for the Fake Product / Fake Review Detection ML project.

## Architecture

Frontend (HTML/CSS/JavaScript)
        |
        v
Flask Web Server
        |
        v
Text Cleaning -> TF-IDF Vectorizer -> Trained Classifier
        |
        v
Prediction + Probability
        |
        v
Frontend Result

## 1. Add your trained model

Copy these files generated by the notebook into `model/`:

- `logistic_regression_model.joblib`
- `tfidf_vectorizer.joblib`

The names must match exactly.

## 2. Install dependencies

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Then:

```bash
pip install -r requirements.txt
```

## 3. Run locally

From the project root:

```bash
python -m backend.app
```

Open:

```text
http://127.0.0.1:5000
```

## 4. API

### Health check

`GET /api/health`

### Prediction

`POST /api/predict`

JSON:

```json
{
  "review": "The product arrived on time and works exactly as described."
}
```

Response:

```json
{
  "prediction": "GENUINE",
  "class": "genuine",
  "fake_probability": 17.3,
  "genuine_probability": 82.7,
  "confidence": 82.7,
  "review_length": 62,
  "word_count": 11
}
```

## Deployment

This application can be deployed to Render or another Python hosting platform using:

```text
gunicorn backend.app:app
```

The frontend is served by Flask, so users only need a browser. It is responsive for desktop, tablet, and mobile.

## Important

The preprocessing function in `backend/app.py` must remain consistent with the preprocessing used before fitting the TF-IDF vectorizer in the notebook. If your notebook's `clean_text()` differs, replace the Flask version with the exact same function.
